# K 线复盘

从顶部「K线复盘」进入 `/replay`，或在个股行情旁点击同名按钮，直接带入当前股票。此功能用于历史行情回放、记录判断与盘感练习。

## 使用

1. 输入 A 股代码，选择需要载入的历史区间和复盘起点。
2. 用「下一日」逐个交易日推进，或播放并调整速度。支持后退、日期定位与进度拖动；非交易日定位到此前最近的有效交易日。
3. 在图表上方查看当前复盘日期的行情与历史指标，切换日、周、月 K。主图可开启 MA、BOLL，副图可选成交量、MACD、KDJ、RSI 等，最多同时显示 3 个；周期与参数可在[指标设置](KLINE_INDICATORS.md)中调整。周／月 K 只聚合已揭示的交易日，因此最后一根可能尚未走完。
4. 在当前日期记录方向与理由。后退时不展示未来日期的笔记；可导出截至当前节点的记录。笔记保存在当前浏览器，按账户和股票区分，不会同步到其他设备。

快捷键：左右方向键后退／推进一个交易日，空格播放／暂停。编辑输入框时不触发这些快捷键。播放到末尾或切换到后台标签页时会停止。

## 数据口径

- **价格**：历史日线，来源与复权口径在页面标示。图表只接收当前复盘日期及以前的 K 线，均线和副图指标也以此为输入。
- **市值与 PE（TTM）**：有对应交易日的历史数据时展示。不会用当前行情快照或今日股本回填历史市值。
- **归母净利润（TTM）**：按可验证的历史公告时间选取报表，并用当时已公开的报告计算。只有公告日期时，从次日起可见；原报告与修订按各自公布日期选取。报表不足但历史市值与 PE 齐备时，以两者相除估算并标注「估算」；两类证据都不足时留空。
- **成交量**：股；成交额、市值与盈利：元，界面自动换算为万／亿。
- **日量比（前 5 日）**：当日成交量 ÷ 前五个交易日成交量均值。它是收盘后的日级比较，不是交易软件的盘中量比。历史不足或分母为零时留空。
- **换手率、涨跌幅、振幅**：百分数。缺失值显示「—」，不会当作零。

免费行情和付费历史基本面来源的覆盖不同。配置有权限的 Tushare 账户可补充历史市值、PE 和财务报表；没有对应权限时仍可使用可取得的 K 线练习。具体缺口和失败原因以页面提示为准。历史提供方可能修订记录；此回放不保证重现当时交易终端收到的原始版本。

当前按完整交易日推进，不重建盘中每笔成交；未复权行情在除权除息时可能出现跳空。复盘笔记是主观判断记录，不是模拟成交或收益回测。

相同账户与区间的复盘数据保存在本地行情缓存，一天内优先复用；手动「载入复盘」或「重试」会重新获取，配置数据权限后可据此补充指标。在线来源失败时可使用上次缓存，并在页面直接提示。该功能用于本地完整部署，隔离的公开试用服务保持原有接口范围。

## 实现与校验

`GET /api/kline-replay/{symbol}?start_date=YYYY-MM-DD&end_date=YYYY-MM-DD` 返回历史日线及逐日指标、来源和缺失说明。接口遵循现有账户认证。

针对性测试覆盖日期定位、范围边界、周月聚合、未来 K 线不影响已揭示指标、笔记可见性、CSV 转义、历史报表公告时间和缺失数据处理。前端另进行播放、单步、日期跳转和窄屏交互检查。
