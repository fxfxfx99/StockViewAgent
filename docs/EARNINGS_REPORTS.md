# 财报季解读

选中一只 A 股，在 **新闻与财报 → 财报季** 使用。原来的新闻更新、待解读和相关解读继续保留在“新闻”页签。

## 操作流程

1. 点击查找财报，后台获取当前股票近期公告。按年份和报告类型筛选，核对报告期、披露日、公司名称与修订标记。
2. 选择正式财报，可先下载解析，查看文字提取覆盖情况并打开原始 PDF。原文保存在本地，后续可再次下载。
3. 在设置中配置当前账户的模型。填写关注问题，例如“关注经营现金流与应收账款变化”，手动提交解读。后台会在必要时先下载、解析，再调用一次模型。
4. 查看关键指标与八个方面的解读：营收利润、现金流、利润质量、资产负债、业务分部、同比比较、审计风险、后续观察。事实、推断、缺口分别标注；引用可核对原文物理页和摘录。

查找、下载解析和读取历史不调用模型；解读使用账户现有接口，不要求额外配置独立模型。切换股票或账户不会混入此前账户的个人解读。关闭页面后，已提交任务继续由 API 后台处理。

## 来源与报告版本

优先查找 [巨潮资讯](https://www.cninfo.com.cn/new/index) 的正式公告；其股票目录提供真实证券身份，再查询公告。巨潮不可用或没有合适记录时使用 [东方财富公告](https://data.eastmoney.com/notices/)；东财附件通过公告详情获取，不根据编号猜测 PDF 地址。只请求内置可信来源，重定向也验证目标；认证、验证码或上游拒绝会显示不可用，不尝试绕过。

覆盖年报、半年报、一季报和三季报。正式中文全文可供解读，摘要、英文版、业绩预告、业绩快报与单独更正公告明确区分。修订后的全文保留修订标记；标题、公告日期或附件地址改变会形成新的本地版本，已有解读不自动迁移到新文件。

已保存的有效 PDF 会复用；若上游在同一地址、同一公告元数据下静默替换文件，目前不会主动重新检测该变更。

默认查找近三年的近期记录，单次最多返回 30 条；来源分页和发布时间影响覆盖，列表不是整家公司全部历史档案。短时间重复查找有冷却，来源失败保留原列表。财报任务由用户主动提交，没有新增定时付费解读。

## PDF 阅读与引用

原文件以 SHA-256 标识，解析保留每个物理页的文本与状态。页码从 PDF 第一页起计为 1，可能与报告印刷页码不同。单文件最多 30 MiB，提取最多 600 页、100 万字符、单页 3 万字符；解析有独立进程超时及资源限制。达到上限、扫描页、空白页、加密或损坏都会标明，不冒充完整提取；目前不执行 OCR。

模型输入最多约 4 万字符。短报告可发送全部可提取文本；较长报告按财务主题选择页面或片段，报告展示实际发送页码、文字量和缺口。**选页解读不等于通读全部财报**，原文其它部分或附注可能改变结论。

模型输出需通过结构、页码、引文和数字核验：引用须存在于实际发送的原页文本中；指标保留原单位、期间及年度／累计／单季／时点口径，不自动换算或用累计金额相减得出单季。缺少原文支持的指标不应输出，缺少审计报告不能推断审计意见。

PDF 文本抽取可能丢失表格的列关系。引文校验不能代替会计审核，也不能保证模型的语义理解正确；关键金额和期间应回到原页核对。若模型输出不符合证据约束，该次任务显示失败并保留旧解读，不自动再发一次请求。

## 额度、缓存与中断

相同账户、PDF 内容、关注点、模型配置与提示词版本命中已有结果时直接复用，包括从不同来源下载到完全相同的文件。修改关注点、模型配置或选用内容不同的财报版本，会产生新的分析任务；历史解读保留其当时文件标识。

默认每账户每天最多 12 次财报模型请求，由 `EARNINGS_DAILY_CALL_LIMIT` 控制，北京时间换日。财报、观察监控、研究实验室分别计数。模型请求失败也计入；单次输出最多请求 6,000 tokens，实际费用由供应商确定。没有可用文本时不会发送模型请求。

后台通过进程锁、任务租约和原子请求计数防止同一任务重复发送。重复提交同一任务合并；不同关注问题遇到正在处理的任务会提示稍后再提交。服务重启时，尚未发送模型请求的任务可恢复；已经发送、结果未知的任务标为失败，不自动重发。已有文件和成功解读保留。

`ENABLE_EARNINGS=true` 默认启用队列处理；设为 false 并重启后，不处理新的任务，已有资料仍可查看。查找财报与下载 PDF 是公开网络请求，来源可用性仍取决于上游。

## 存储与接口

`STOCKVIEW_DATA_DIR/earnings.sqlite3` 保存公告版本、来源状态、任务、请求计数及个人解读；`earnings/files/<sha>.pdf` 保存原文，`earnings/text/<sha>.json` 保存逐页文本。都属于长期资料，随整个数据目录备份迁移，不纳入展示缓存回收。正式财报及原文可在本机账户之间复用，用户的关注问题、模型报告和任务按账户隔离。

接口统一要求当前账户身份，公开试用网关不开放：

| 接口 | 用途 |
|---|---|
| `GET /api/news/earnings?symbol=600519.SS` | 本地目录、来源状态、个人任务、模型配置状态和额度 |
| `POST /api/news/earnings/refresh` | 请求体含 symbol，提交查找任务 |
| `GET /api/news/earnings/{id}` | 财报、解析覆盖和当前账户历史解读 |
| `POST /api/news/earnings/{id}/prepare` | 提交下载及解析 |
| `POST /api/news/earnings/{id}/analyze` | 提交解读，可含 focus；必要时先准备原文 |
| `GET /api/news/earnings/{id}/pdf` | 下载本地原始 PDF，使用正常账户鉴权 |

全部 GET 接口不触发查找、下载或模型请求；不会把密钥放入 PDF 链接。
