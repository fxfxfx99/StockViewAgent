# 策略介绍、知识库与 RAG

从 **工具 → 策略知识库** 或个股 **决策分析 → 多策略观点** 的策略入口进入。每个策略都有独立地址 `/strategies/:strategyId`，涵盖目前全部 16 个研究视角。

## 介绍与分析视角

介绍页说明策略关注什么、基本原则、适用条件、容易失效的情形及需要核验的证据。策略目录沿用现有的名称和观察周期。观点的方向、评分与置信度仍由现有行情、资金和财务规则计算；新增资料用于补充依据与风险，不因资料增加而自动提高置信度。

## 独立知识库

每个账户、每个策略分别保存补充资料，包括标题、正文、来源链接、资料日期和标签；支持新增、修改和删除。资料保存在服务端 SQLite，刷新浏览器或重启服务后仍保留。账户之间、策略之间不混用私人资料。

内置方法说明和已保存的公开来源按策略归类展示。来源链接作为引用保存，新增私人资料不会自动抓取链接。管理员可以在单个策略中更新预置的公开来源，更新失败保留已有资料，并显示失败数量；重复抓取相同内容不会把旧资料伪装成新内容。

## RAG 配置

各策略分别设置：

- 是否启用知识检索。
- 检索条数 `top_k`。
- 资料时效窗口 `max_age_days`，留空表示不限制。
- 是否包含内置与共享资料。
- 是否优先较新的资料。

检索在本地完成，采用文本相关性匹配和时间排序，不需要向量数据库或外部 Embedding API。检索预览可输入问题和历史日期，检查实际命中的资料、版本及筛选结果。关闭某个策略的 RAG 不影响其他策略，也不会关闭独立配置的经济日历和公共数据背景。

## 随资料更新的分析

新增或修改资料、调整 RAG 参数后，后续分析使用最新保存的配置和资料版本。返回个股决策分析或点击刷新即可重新读取；行情和财务资料仍沿用项目现有的数据采集计划。无需模型调用即可完成本模块的管理、检索和规则分析。

每份分析记录知识版本、RAG 配置版本和引用资料的版本、更新时间。保存为关注判断时，一并保留当次知识引用与摘要，后续修改资料不会覆盖已经保存的判断。

选择历史日期时，以北京时间当天结束为截止，私人资料与 RAG 配置只使用该时间前已经保存的版本；当时还未保存配置则使用默认值。填写较早的资料日期不能让今天录入的资料进入过去。共享公开资料目前只有当前快照，若快照晚于截止时间则排除；方法介绍作为当前方法说明单独标识。历史分析仍使用当前评分程序及可能经过当前复权的行情，不等同于严格的时点回测。

此功能支持持续补充、修订和重新分析。它不会自行改变评分算法，也不承诺自动抓取全网或自动学习后提升策略收益。
