# 美林时钟

顶部 **美林时钟**（`/merrill-clock`）提供中国和美国两套周期判断。左侧比较跨资产周度曲线，右侧在增长／通胀四象限时钟上标出阶段；下方展示理论、指标计算和当前账户的模型解读。

## 数据库与覆盖

`STOCKVIEW_DATA_DIR/merrill.sqlite3` 保存20条资产序列、宏观月度观测、来源与覆盖、同步状态和个人解读。默认位于 `backend/data/merrill.sqlite3`，随整个数据目录迁移，不属于普通缓存。

| 类别 | 序列 | 口径 |
| --- | --- | --- |
| 股票 | 标普500、纳斯达克综合、道琼斯、罗素2000、富时100、德国DAX、日经225、恒生、上证综指、沪深300 | 指数收盘；不同指数的价格／收益口径并不完全相同 |
| 债券与信用 | 10年美债、长期美债、投资级债、高收益债 | 10年美债为收益率；后三者分别使用TLT、LQD、HYG ETF复权收盘代理 |
| 商品 | 标普GSCI、黄金、白银、WTI原油 | GSCI指数；后三者为连续期货报价，含换月影响，不是总回报 |
| 汇率与现金 | 美元指数、3月美国国库券 | 美元指数；国库券为贴现收益率，非现金组合净值 |

采集请求回溯五十年，实际覆盖由指数设立、ETF成立时间和公开源历史决定。**不足五十年的序列不会外推、拼接其他资产或伪造数据。** 页面列出最早／最新观测、周数、来源、代理说明和失败状态。下载失败保留已有数据。

日行情按周五归属，取该周最后一个有效交易日收盘，保留真实交易日期；只保存已结束的周，缺周不前填。收益率使用独立百分比坐标，不能解释为债券价格回报。图表支持归一基准100、原值、区间回撤。

## 两套时钟的算法

- 美国：FRED `INDPRO`工业生产指数、`CPIAUCSL`消费者价格指数，先计算月同比。FRED不可达时使用同口径的美联储G.17季调工业生产、BLS季调CPI官方数据，记录实际来源。
- 中国：国家统计局口径的制造业PMI月度水平、全国CPI同比，经东方财富公开宏观接口采集。PMI直接比较水平变化，CPI同比直接使用，不再次同比。工业增加值同比另行保留作参考，不把一至二月合并数据拆为单月。
- 两轴分别比较最近三个连续月均值与此前三个连续月均值，使用共同月份。美国两轴和中国通胀轴以同比百分点衡量；中国增长轴以PMI指数点衡量。PMI动能反映变化方向，与PMI是否高于50的扩张／收缩判断不同。
- 上方增长加速，下方增长减速；左侧通胀回落，右侧通胀上升。左上复苏、右上过热、右下滞胀、左下衰退。动能接近零显示过渡；不足或陈旧不显示当前节点。

这是可复算的双指标实现，不是美林或Royal London官方模型。工业生产和制造业PMI是增长代理，不等同GDP；“衰退”是规则象限标签，不是官方衰退认定。宏观数据按月发布且可能修订，每周刷新不意味着每周新增宏观观测。观测月份与采集时间分别保留；修订后历史不能当作当时的实时可得信息。

参考：[Royal London Investment Clock](https://www.rlam.com/uk/intermediaries/our-capabilities/multi-asset/investment-clock/)、[FRED工业生产](https://fred.stlouisfed.org/series/INDPRO)、[FRED CPI](https://fred.stlouisfed.org/series/CPIAUCSL)、[国家统计局](https://www.stats.gov.cn/sj/zxfb/)。

## 每周更新与模型

`ENABLE_MERRILL_CLOCK=true` 时API后台独立运行，每周六北京时间08:00更新，初次补历史，停机重启后补跑。关闭浏览器不影响后台，电脑或后端停机期间不会执行。

每周AI开关按账户保存，启用后分别更新中国与美国解读，复用当前账户已有模型配置。模型接收本地区指标、资产摘要、日期和缺口，解释确定性计算结果，不修改阶段。中美分别生成保存；未配置、失败、旧报告和本期报告明确区分，请求保留用量记录并有频率限制。

公共采集共享，个人解读按账户隔离。手动刷新公共数据需要管理员权限。多进程通过持久状态和文件锁协调，失败保留已存数据及报告。

## 操作

1. 打开美林时钟，切换中国／美国查看依据。
2. 选择资产、窗口和曲线类型，展开数据覆盖查看来源和历史长度。
3. 在设置中配置账户模型，然后生成解读或开启每周解读。
4. 管理员可手动同步；首次回填脚本：`./backend/.venv/bin/python backend/scripts/merrill_backfill.py`。

实际成功条数与覆盖以数据库／页面为准，代码测试不能代替真实采集验证。
