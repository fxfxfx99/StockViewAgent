# 关注个股、研究与监控

主工作流是 **关注个股 → 研究 → 监控 → 带证据更新研究**。三个入口共用当前账户身份，但人工判断、模型报告、监控计划分别保存，不会因为生成新报告而自动替换用户判断。

| 入口 | 路径 | 用途 |
|---|---|---|
| 关注个股 | `/` | 股票列表、行情与资料；查看当前股票的研究、监控和本地财务历史 |
| 研究 | `/research` | 公司、股票列表或主题档案；整理问题、材料、历史报告与当前采用的研究 |
| 监控 | `/monitor` | 按计划检查本地资料，处理变化提醒并记录复盘决定 |

原来的量化研究实验室移到 **工具 → 量化研究实验室**（`/lab`）；原 `/api/research/*`、策略实验、自动研究预算与模拟账户保持原有用途。新研究使用独立 `/api/investment-research/*`。今日变化、市场研判、海外快讯、经济日历和数据中心保留在工具入口，K 线复盘仍有独立入口。

## 建立研究档案

1. 从当前股票进入研究，或在研究页新建档案。对象可为个股、1–20 只股票的固定列表，或至少一个关键词的主题。
2. 填写研究目标和自己的当前判断，补充待回答的问题。问题可记录人工答案，并标为待回答、已回答或暂放。
3. 添加笔记、粘贴文字，或上传 UTF-8 的 TXT／Markdown、PDF。也可从同一研究对象的已完成监控任务导入变化与证据。
4. 配置当前账户的大模型接口后，明确点击生成研究。研究无需额外的连接验证请求；监控仍按自己的规则要求连接验证。
5. 查看摘要、事实／解读／资料缺口、判断变化、未决问题、下一步观察及引用。确认后点击采用，才把该报告设为当前研究。

建立档案、维护问题与材料、读取历史、标记已读和采用报告不调用模型。档案保存的 `thesis` 是人工判断；采用模型报告另外保存报告关联与采用历史，不覆盖这段人工文字。采用同对象的历史报告时仍显示其原版本与生成时间，不能当成新生成报告。对象改变会清除当前采用关联，旧报告仍保留，不能采用为新对象的研究。

股票列表成员规范化并去重，最多 20 只。导入自选只保存当时的名单，后续自选变化不会自动改写研究或监控对象。列表资料按成员分配空间并显示覆盖，不能拿一股资料断言全列表已满足条件。

## 材料、证据与阅读范围

研究读取已有本地资料，并结合当前档案的私有材料。新闻、行情、技术指标、已保存策略观点、公司公告、论坛讨论共六类资料按实际覆盖提供；其中新闻还包含匹配的海外新闻、公共资料与经济日历。来源定义见 [观察与复盘](OBSERVATION_MONITORING.md#数据范围与解释)。生成时不临时抓取网站，不自动调用其他解读或付费向量化服务。

用户笔记、上传文件、论坛讨论、已保存策略与旧模型报告均保留来源身份，不能冒充已经独立核实的经营事实。公告目录只能证明目录记录存在，不能冒充已阅读全文；技术指标是本地行情计算结果。报告引用必须来自本次实际提供的片段；没有来源、日期未知、陈旧或不完整的材料会显示限制。证据不足时保留未决问题，不把缺失资料解释为没有变化。

PDF 按物理页保存提取文字和覆盖情况，**不执行 OCR**。扫描页、加密、损坏、超限或超时会显示状态；解析失败可明确重新解析，不调用模型。单文件最多 30 MiB，解析最多 600 页、总计 100 万字符、单页 3 万字符，解析进程最长约 30 秒。每档案最多 30 份材料，保存的材料内容总量限制约 400 万字符；普通文本材料最多 50,000 字符。模型只读取选中的有界片段，不能据此宣称通读完整文档。

上传材料存入当前账户的研究空间，不加入旧的全局公司资料上传库。监控导入只接受任务 ID，后台读取同账户成功任务的原始快照；用户不能自行替换其中证据。同一监控任务重复导入同一档案不会重复新增材料。

## 研究与监控的往返

研究报告最多给出五条下一步观察，包含标题、目标、观察条件与失效条件。点击后预填监控草稿，用户确认对象、来源、频率与复盘日期并保存后才启用；报告生成或采用不会自动开启计划。

监控报告出现结论、条件或证据变化时，可以打开触发任务，查看当时对象、检查日期、证据与模型结论，再继续已有档案或创建对应研究档案。导入本身不生成新报告、不产生研究模型请求；需要用户明确生成更新。此前监控结论作为历史观点保留，其原始证据单独引用。

**已读与已处理分别记录。** 已读表示看过提醒；已查看、忽略或转入研究属于处理决定，需填写理由并保存来源任务快照。查看页面或标已读不会代替处理，转入研究也不代表研究假说已成立。人工复盘的继续、修改或关闭决定另行保存。

## 后台、额度与配置

| 配置 | 默认值与行为 |
|---|---|
| `ENABLE_INVESTMENT_RESEARCH` | `true`；API 内独立处理手动提交的研究与 PDF 解析任务 |
| `INVESTMENT_RESEARCH_DAILY_CALL_LIMIT` | `12`；每账户北京时间每日研究模型请求上限，范围 1–100 |

该 worker 独立于 `ENABLE_SCHEDULER`、量化研究 worker 和监控 worker。API 运行期间，即使关掉页面也会完成已提交任务；没有手动任务时不会自动研究或调用模型。大约每 5 秒检查队列，每轮最多处理三个任务，同一档案同时最多一个生成任务。

每个研究任务至多发送一次模型请求，无请求内自动重试、供应商切换或密钥轮换。失败请求也计入研究额度；这 12 次独立于监控、财报季和量化实验室额度，不是金额上限。单次模型上下文最多约 32,000 字符，输出最多请求 6,000 tokens。

相同有效输入、材料与证据、模型配置及提示版本可复用已有报告，不增加请求。没有可用材料时保存资料不足结果，不调用模型；仅有用户观点时可整理待验证问题，但不据此升级为有独立事实支持的结论。

编辑问题、材料或档案会更新版本，并取消未派发的旧生成任务；模型已发送的任务可能继续完成，但只写入旧快照对应的历史报告，不覆盖人工判断或当前采用报告。归档停止新生成，保留材料和历史。进程锁、租约与原子额度防止并发重复派发；重启后已派发且结果未知的任务记为 `interrupted_after_dispatch`，不会自动重发。显式再次提交是新的请求，可能再次计费。

## 个股财务历史

关注个股中的 **财务图表** 读取本地导入的财务记录。`GET /api/stocks/{symbol}/fundamentals/history` 默认返回最近 12 条，最大 100 条；只读本地 SQLite，不发起网络请求，也不会为了空结果创建或补采财务数据库。

返回原始字段名、数值、来源文件名、报告期、报表类型、观测时间与已有的披露时间。只有原始字段明确给出单位或值带百分号时才提供单位；未知单位保留为空，不自行解释为元、万元或亿元，不自动换算。应按相同报表类型和可比报告期比较，不能把累计数当单季数，报告期也不代表披露时点。旧资料的保留不等于已经具备严格历史可得性。

## 保存与接口

`investment_research.sqlite3` 保存账户档案及版本、问题、材料、任务、不可变报告、已读、采用历史与独立请求计数；原始 PDF 位于 `investment_research/<账户ID>/`。二者都是长期资产，跟随 `STOCKVIEW_DATA_DIR` 整体备份与迁移，不参与展示缓存回收。移除材料会从当前研究输入排除它，已冻结历史不会随之改写，不等于彻底擦除历史或原文件。

| 接口（前缀 `/api/investment-research`） | 用途 |
|---|---|
| `GET /overview?symbol=...`、`GET /dossiers` | 当前账户档案、采用摘要、未读、任务、额度与后台状态 |
| `POST /dossiers`、`GET/PATCH /dossiers/{id}` | 建立、读取或带 revision 修改档案；可带 `monitor_run_id` 建档 |
| `POST /dossiers/{id}/questions`、`PATCH/DELETE /questions/{id}` | 保存问题和人工答案，修改或删除校验版本 |
| `POST /dossiers/{id}/materials`、`POST /dossiers/{id}/materials/upload` | 文本／监控材料、文件上传 |
| `POST /dossiers/{id}/monitoring-updates` | 按成功监控任务 ID 幂等导入 |
| `GET/DELETE /materials/{id}`、`GET /materials/{id}/pdf`、`POST /materials/{id}/prepare` | 同账户材料读取、移除、原PDF和重新解析 |
| `POST /dossiers/{id}/generate`、`GET /jobs/{id}`、`POST /jobs/{id}/cancel` | 明确提交、读取或取消尚未派发的任务 |
| `GET /reports/{id}`、`POST /reports/{id}/adopt`、`POST /reports/{id}/read` | 历史报告、明确采用与已读 |

公开试用网关不开放研究、监控、量化实验室页面及这些私有接口。完整本地部署中按当前账户授权；免登录模式使用本地默认账户，不能据此宣称公网匿名访问具有账户隔离。
