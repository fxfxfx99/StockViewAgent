# 本地数据中心、自动采集与缓存管理

从 **工具 → 数据中心**（`/data`）进入。管理员可以浏览文件分类、筛选已采集资料、调整采集频率、查看任务与来源状态，以及预览缓存清理和恢复回收文件。数据中心管理本机共享资料；普通账户不能调用这些管理接口，本地免登录模式使用本地默认管理员身份。

## 页面与首次使用

- **文件与分类**：按分类、来源、生命周期、路径关键词筛选和分页，查看大小、更新时间、保护状态与到期时间；文件正文和密钥不随目录索引返回。
- **已采集数据**：查看数据所属时期、数值、本地采集时间、来源链接、修订引用和批次标识。新闻和经济日历继续使用各自的专用页面与数据库。
- **采集与任务**：区分排队、运行、成功、部分成功、失败和跳过，查看接收条数、新增条数、最近成功与错误码。
- **缓存与回收区**：设置保留天数，先预览再回收；可以恢复整个批次，也可以确认后永久删除仍在回收区的缓存。

点击 **自动采集配置** 可调整股票池、来源开关、每日时间或间隔，以及后台资源阈值；**立即采集** 只提交任务，等待后台完成后才会更新资料。只刷新文件索引不会访问上游，也不会触发模型解读。采集和缓存管理本身不调用大模型、不主动选用付费数据源。

页面分页、新闻显示条数和页面刷新频率只控制呈现；后台采集有独立的频率、批大小、并发、内存准入与任务预算。当前新闻页面从本地归档读取，采集按钮提交后台任务。兼容保留的旧新闻 GET 接口仍可能联网，外部客户端应优先使用 `/api/news/archive` 和海外归档接口，不能把所有 GET 请求都视为本地读取。

## 采集范围与来源

当前有 **12 类逻辑采集任务**：6 类复用业务数据采集，另加 6 类官方数据源。六类官方来源来自欧洲央行、世界银行和美联储，指六个采集适配，不是六个不同机构。

| 任务 | 内容 | 新安装默认调度 |
|---|---|---|
| `public_market` | 上证、深成、创业板、沪深300、上证50的公开日线，归档并预热市场研判 | 1 小时 |
| `public_kline` | 腾讯公开 A 股前复权日线，保存版本并更新 K 线展示缓存 | 每日北京时间 17:30 |
| `public_news` | 已接入的个股 RSS、财经快讯和科技媒体新闻，归档到新闻库 | 2 小时 |
| `public_company` | 东方财富公开公司简介、主营与公司概况 | 每日北京时间 17:30 |
| `public_capital_flow` | 个股日资金流，并合并累计历史序列 | 每日北京时间 17:30 |
| `economic_calendar` | 美联储、欧洲央行、日本央行、中国统计局、美国劳工统计局五个官方日历 | 1 小时 |
| `ecb_fx` | [欧洲央行参考汇率](https://www.ecb.europa.eu/stats/eurofxref/eurofxref-hist-90d.xml)，上游近约 90 天 | 6 小时 |
| `wb_gdp_growth` | [世界银行实际 GDP 年增长率](https://api.worldbank.org/v2/country/CN;US;JP;DE;GB;IN/indicator/NY.GDP.MKTP.KD.ZG?format=json) | 24 小时 |
| `wb_inflation` | [世界银行年度消费价格通胀率](https://api.worldbank.org/v2/country/CN;US;JP;DE;GB;IN/indicator/FP.CPI.TOTL.ZG?format=json) | 24 小时 |
| `wb_unemployment` | [世界银行年度失业率（ILO 模型估计）](https://api.worldbank.org/v2/country/CN;US;JP;DE;GB;IN/indicator/SL.UEM.TOTL.ZS?format=json) | 24 小时 |
| `fed_policy` | [美联储货币政策公告 RSS](https://www.federalreserve.gov/feeds/press_monetary.xml) 的标题、摘要、发布时间和原文链接 | 1 小时 |
| `ecb_publications` | [欧洲央行公告与讲话 RSS](https://www.ecb.europa.eu/rss/press.html) 的标题、摘要、发布时间和原文链接 | 1 小时 |

世界银行三项指标请求中国、美国、日本、德国、英国、印度近十个自然年的年度数据。年度值是当前下载版本，可能已被上游修订；缺值保留为空，不补造预测。参考汇率按「一欧元兑换多少外币」解释，并非实时成交报价。政策 RSS 保存来源实际提供的摘要，不自动抓取文章全文。资金流为公开订单分类口径，不代表已识别机构身份。

每个来源可独立设置 `schedule_mode=daily` 和 `daily_at=HH:MM`，或 `schedule_mode=interval` 与 `interval_minutes`。每日时间按 `Asia/Shanghai` 计算。已有安装中保存过、尚未包含 `schedule_mode` 的来源继续使用原间隔；升级不会静默改成每日任务。股票行情、公司和资金流切回间隔模式时，初始间隔分别为 6、24、6 小时。

首次启动或停机后恢复时，尚未完成的最近到期窗口可以立即排队；例如当天 17:30 前启动的新实例可先执行上一天的到期窗口。它会采集上游当前可用数据，不逐日回放停机期间的每个窗口。

来源清单是固定地址白名单，不能通过管理接口提交任意爬取 URL。上游拒绝请求、超时或内容格式改变时记录失败，已有成功资料与历史证据保留。网页的「已配置来源」不表示已经成功取到数据；应核对最近成功时间和实际入库条数。

## 自动运行、预算与停用

默认配置如下：

| 设置 | 默认值与含义 |
|---|---|
| 自动采集 `enabled` | 开启；依赖 API 服务与 `ENABLE_DATA_COLLECTION=true`，独立于 `ENABLE_SCHEDULER` |
| 每日任务上限 `daily_job_limit` | 北京时间每天 120 次开始执行的逻辑任务；失败、重试与中断后的重启尝试也计入 |
| 每批股票数 `max_symbols_per_cycle` | 每个股票类任务默认 10 个，允许 1–30；同一整轮持续提交剩余股票批次 |
| 自定义股票 `symbols` | 初始为空，可配置最多 300 个 `六位代码.SS/SZ/BJ` |
| 读取已有自选 `use_watchlists` | 开启，与配置股票合并去重；不改写已有列表，不为主动清空的列表重新补示例 |
| 最低剩余空间 `min_free_disk_mb` | 1024 MiB，即 1 GiB；低于下限时暂停领取任务，保留队列与历史资料 |
| 来源并发 `max_concurrent_jobs` | 默认 1，允许 1–3；限制中央 worker 的同时执行任务数，也供其他采集器各自限制并发 |
| 内存准入 `max_memory_mb` | 默认 768 MiB，允许 128–8192；当前 API 进程 RSS 达到阈值时暂停启动后续工作 |
| 任务超时 `job_timeout_seconds` | 默认 240 秒，允许 30–600 秒；取消后仍等待已经开始的线程操作收尾 |
| 海外自动采集 `overseas_enabled` | 初始取环境配置；独立控制海外循环，可在线暂停与恢复 |
| 海外轮询 `overseas_poll_interval_sec` | 默认 120 秒，允许 60–3600；来源冷却可能使实际间隔更长 |
| 公共资料 RAG `rag_enabled` | 开启，独立控制已采集公共资料是否进入 Agent 检索 |

**120 是逻辑任务次数，不是 HTTP 请求数或模型 token 额度。** 一个任务可能包含多只股票、多条 RSS 请求、五个指数或五个日历来源；手动任务也使用同一每日额度和磁盘检查。空股票池时，个股行情、公司和资金流不自动入队、不空耗额度；大盘指数、公共新闻、六类官方来源及经济日历仍独立执行。后台只读已有股票列表，不创建示例自选。

股票类来源开始一整轮时冻结股票名单，逐批保存已完成股票的检查点。最后一批完成才结束整轮并计算下一次调度；失败股票继续保留在待完成名单中，成功股票无需整轮重采。每日预算不足、暂停或服务重启时保留进度，恢复后继续剩余批次，不能保证任意规模股票池都在当天完成。轮内修改配置股票池影响下一整轮；共享自选合并后的新整轮超过 3000 只时明确阻止启动，不会静默截断。

采集 worker 在 API 启动约 10 秒后开始轮询，默认 **1 个来源任务并发、每次轮询最多 8 次尝试**，约每 5 秒再次检查队列；同一数据目录通过进程锁避免重复执行。每一批股票任务占用一次每日额度，并非整个股票池只计一次。间隔来源从整轮完成时计算下次时间，失败或部分失败按 2 分钟、4 分钟等指数退避，最多 6 小时；401/403 至少冷却 30 分钟，429 至少 5 分钟。手动重复提交有来源冷却与活跃任务去重。跳过不增加失败次数，新闻中单个提供方失败不会丢弃其他提供方成果。

内存阈值是**当前进程的协作式准入检查，不是内存硬上限**。Linux 读取当前 RSS，macOS 使用当前进程 `ps` 采样，约缓存 5 秒；不支持或读取失败时返回 `supported=false`。高内存时暂停新任务，已有任务正常收尾，内存回落后后续轮询自动恢复。中央 worker、海外循环、启动预热和公司更新分别检查资源；各采集器各自使用并发限制，不能将配置值理解为整个 API 服务的总并发硬上限。每日任务额度只约束中央任务队列，海外独立循环与启动检查不计入该额度。

任务线程中的网络或文件操作在取消时会先收尾再释放锁，实际收尾可能超过名义超时。未完成任务在重新取得锁后恢复，尚未尝试的队列任务优先，避免中断任务长期占满额度。关闭服务后不会继续采集，重启会检查持久队列与到期来源；这不等于回补停机期间的所有历史数据。来源状态返回 `round_id`、`round_status`、`total_symbols`、`completed_symbols`、`pending_symbols`、`scheduled_for`、`next_run_at`、`last_finished_at` 与 `duration_seconds`；运行状态中的 `automatic_enabled`、`resources` 和 `reason` 解释开关、内存与预算等待。

| 开关 | 影响 |
|---|---|
| 页面关闭「自动采集」或单个来源 | 停止对应自动排队，并取消尚未执行的对应自动任务；显式提交的手动任务仍可处理，当前已开始操作按正常收尾处理 |
| 页面关闭「海外自动采集」 | 停止海外来源的新请求，循环保留以便在线恢复；与中央自动采集开关分别控制 |
| `ENABLE_SCHEDULER=false` | 不影响中央自动采集；只关闭仍使用旧调度器的任务，例如定时评论与 K 线批解读 |
| `ENABLE_DATA_COLLECTION=false` | API 不启动中央采集 worker，手动队列也不会由它执行；若 `ENABLE_SCHEDULER=true`，经济日历回退到原有独立定时监控 |
| 缓存策略「自动回收」 | 单独设置，默认关闭；与页面自动采集开关分别控制，中央 worker 运行时最多每小时检查一次 |

环境变量修改后须重启。页面暂停中央自动采集或只关闭日历来源时，不会另外启动日历备用调度；只有环境变量关闭中央 worker 才采用上述日历 fallback。中央日历任务也受每日预算、磁盘空间和队列等待影响，不保证每个整点完成。多副本部署仍建议只为指定调度实例开启 `ENABLE_SCHEDULER`。

## 新闻采集的内存边界

通用新闻 HTTP 下载同时限制传输和解压后正文，默认每响应最多 **2 MiB**；gzip/deflate 在解压过程中限制输出大小。超限、非 200 和限流响应不会立即重复下载。RSS 每次最多并发 2 个，取到即解析并释放原始正文，股票新闻也按最多 2 只分批请求。后台归档采用小批写库，不受 `news_feed_max_items` 页面条数限制；实际覆盖仍受各来源返回窗口和单源条数上限限制，不等于抓取全部历史。

启动检查、中央队列和其他调用 `sync_all_sources_to_archive` 的入口共用进程锁；重复运行返回 `skipped/already_running`，高内存返回 `skipped/high_memory`，中央队列分别映射为 `source_busy`、`memory_pressure`。取消时保持锁直到当前写库线程结束，已提交内容保留。

本地受控实验使用 100 只股票、204 个各 64 KiB 的假 RSS 响应、80 条展示上限：请求同时在途数量由 204 降到 2，`tracemalloc` 的 Python 分配峰值由约 13.0 MiB 降到 0.093 MiB。该结果只衡量此 RSS 模拟路径的分配峰值，排除真实网络与 TLS，并非生产 API 进程 RSS 或整体内存的测量值。

## 分类存储与可追溯版本

所有目录跟随 `STOCKVIEW_DATA_DIR`，默认 `backend/data/`：

| 位置 | 保存内容与保留规则 |
|---|---|
| `data_center.sqlite3` | 采集配置、任务、每日额度、来源状态、批次目录、不可变记录修订与 FTS5 文本索引，长期保护 |
| `datasets/<分类>/<来源>/<批次哈希>.json` | `market/company/capital_flow/macro/fx/policy` 等公开数据的不可变内容批次，长期保护 |
| `news.db`、`economic_events.sqlite3` | 新闻、日历及各自修订和检索资料，继续由原模块管理 |
| `monitoring.sqlite3` | 按账户保存观察计划、报告、人工复盘、提醒及调用计数，长期保护 |
| `investment_research.sqlite3`、`investment_research/<账户ID>/` | 私人研究档案、问题、材料、原始PDF、报告、采用记录与单次模型任务，归入研究与策略证据，长期保护 |
| `earnings.sqlite3`、`earnings/` | 财报版本、原始PDF、逐页文本、个人模型解读与任务，长期保护 |
| `market_history_cache/` | 累计市场历史序列；上游未必能完整重建，自动维护长期保留 |
| `kline_bundle_cache/`、`market_source_cache/`、`tushare_daily_cache/` | 已知格式的可重建展示或接口缓存，满足期限与校验后才可回收 |
| `_managed/catalog.json`、`INDEX.md` | 相对路径目录索引与分类说明，可刷新 |
| `_managed/cache/` | 缓存策略、预览计划与管理锁；不保存抓取凭据 |
| `_managed/quarantine/` | 可恢复的缓存文件与批次操作记录，直到管理员手动确认永久删除 |

相同内容重复采集不增加修订；内容变化会新增修订，保留 `dataset:<记录ID>:<修订ID>`、批次哈希、来源链接与本地 `observed_at`。索引中的分类和生命周期帮助判断保留方式，不能仅因目录名称包含 `cache` 就认为可删。上传原件、账户、配置、备份与研究证据始终受保护。

新研究档案的材料按账户授权，不因数据中心可列出文件元数据而变成共享资料，也不加入旧的全局公司上传库。删除当前材料只把它排除于后续研究输入，不改写已冻结报告或自动擦除原文件。监控提醒的处理历史与研究报告的采用历史分别长期保留；整体备份时同时携带相应数据库与PDF目录。详情见 [研究工作台](INVESTMENT_WORKSPACE.md)。

## 公共资料进入 Agent 检索

**自动采集配置 → 将公共资料用于 Agent 检索** 是本机共享的 `rag_enabled` 开关，控制实际检索结果。关闭它不会删除已有资料，也不会关闭采集。经济日历仍使用自己的账户级 Agent 配置，详见 [日历说明](GLOBAL_EVENTS.md)。

已接入的新闻、多策略与选股、量化研究、个股 K 线解读会读取本地公共资料库，检索公司资料、政策、年度宏观和参考汇率，以 `D*` 引用附带来源、统计期、采集时点和修订。检索采用结构化分类与 SQLite FTS5/BM25，不需要额外 embedding 服务；只读已采集资料，不在解读期间临时抓取上游，也不因宏观资料存在而自动增加策略得分。

历史检索先选 `observed_at <= as_of` 的可见修订，全文检索的排名语料也受同一时间边界约束，再按相关性与最新统计期限制上下文。后来采集到的旧年份数据、后续上游修订不会进入更早的模拟时点。查询无结果或检索失败时应明确资料不足。

**本地观测 PIT 不等于上游历史 vintage。** 世界银行返回的是当前版本：`period=2020` 表示统计年份，不能据此认定这些数值在 2020 年已经公布、当时可用或未经修订。新安装实例不会拥有过去的本地观测记录。年度指标不能替代月度 CPI 或实时就业数据，参考汇率不能替代成交价；公共资料只作研究事实与背景，不会自动成为严格回测因子。

## 缓存预览、回收与永久删除

自动缓存维护默认 **关闭**。管理员可以手动预览并执行，或在「缓存策略」单独开启每小时自动检查。默认期限如下：

| 白名单目录 | 默认保留天数 |
|---|---|
| `market_source_cache/` | 7 天，来源健康记录除外 |
| `kline_bundle_cache/` | 90 天 |
| `tushare_daily_cache/` | 180 天 |

只有已知格式、包含有效 `saved_at` 与 `payload` 的普通 JSON 缓存可回收；时间校验采用文件修改时间与保存时间中较晚者。SQLite 主库和 WAL/SHM/日志、累计历史、上传、凭据配置、研究数据、公开资料批次及未知格式都不会加入清理。符号链接、硬链接、目录越界与状态发生变化的文件会被拒绝或跳过。

预览计划有效 30 分钟，执行前重新验证路径、期限、文件状态与 SHA-256。默认每批最多 500 个文件、256 MiB；单文件超过 32 MiB 的在线核验限制时会保留，并说明原因。恢复不会覆盖原路径已有的新缓存，冲突文件继续留在回收区。

默认 **2 GiB 活跃缓存预算是监控参考，不是整个数据目录的硬盘 quota**。超额不会淘汰未到期缓存，更不会删除长期资料。不可变历史、备份、数据库和回收区可能继续增长，应结合文件统计与剩余空间管理。

**移入回收区不会释放磁盘空间。** 系统不会按回收天数自动永久删除。确定无需恢复后，管理员在回收批次上点击「永久删除」并确认，后端只删除该批次仍在回收区、指纹与内容校验一致的缓存；已恢复、发生变化或不匹配的文件跳过。删除无法恢复，返回的字节数为成功删除文件的大小，实际可用空间由文件系统决定。需要完整备份或搬迁时，先按 [本地数据目录与搬迁](LOCAL_SETUP.md#本地数据目录与搬迁) 停止写入并处理 SQLite WAL。

## 管理 API

所有 `/api/data-center` 接口要求管理员身份；公开试用网关不开放数据中心页面或管理接口。

| 接口 | 用途 |
|---|---|
| `GET /overview`、`GET /files` | 目录概况、分页文件、来源筛选、生命周期与容量统计 |
| `GET /collection/status` | 轻量轮询采集配置、来源、任务、预算和 worker 状态；不扫描文件目录、不启动抓取 |
| `GET /inventory/summary` | 按需扫描文件容量与分类汇总，不返回完整文件条目；独立于采集状态轮询 |
| `GET /records` | 已采集公开资料、统计期、引用与批次 |
| `GET/PATCH /config`、`GET /sources`、`GET /jobs` | 采集配置、来源状态、队列与预算 |
| `POST /collect` | 提交内置来源任务，可传 `source_ids` |
| `GET/PATCH /cache/policy` | 缓存期限、预算、批次限制与自动维护开关 |
| `POST /cleanup/preview`、`POST /cleanup/apply` | 生成预览，再用 `plan_id` 执行隔离 |
| `GET /trash`、`POST /trash/{batch_id}/restore` | 查看回收批次并恢复 |
| `DELETE /trash/{batch_id}` | 请求体必须含严格布尔值 `{"confirm":true}`，永久删除符合校验的回收缓存 |

表中路径均以 `/api/data-center` 开头。索引刷新沿用已有的数据资产管理接口；文件管理 API 返回元数据，不提供任意路径文件读取或任意文件删除能力。
