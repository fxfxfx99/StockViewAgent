# 市场研判与 ExStockNEWS 2.0 功能整合

从顶部 **工具 → 市场研判**（`/macro`）进入。本工作台复用现有图表、登录、配置、行情链与研究服务，整合 ExStockNEWS 2.0 的宏观与行业、资金概览、大盘解读和个股 K 线研究入口。原项目的账户、数据目录、API 密钥与上传资料没有自动复制；继续使用本工作台自己的数据目录与凭据。

## 页面功能

| 页签 | 功能与数据条件 |
|---|---|
| 全球市场 | 6 个 A 股指数、7 个美股指数及 6 个商品连续期货（品种见下表）；公开行情，无需 Key；支持日／周／月、3个月至5年区间、MA/BOLL 主图及最多 3 个指标副图，参数可调，缩放联动（见[指标设置](KLINE_INDICATORS.md)） |
| 宏观与行业 | 上证／深成／创业板沿用公开行情；上海金 Au99.99、离岸人民币、布伦特及申万行业按当前账户 Tushare Token 与接口权限获取；周／月由日线合成 |
| 资金概览 | 行业资金多周期与反转、机构和情绪代理、北向与两融历史；展开后读取人气／热门概念，按输入查询 ETF 与个股资金流 |
| K线解读 | 所选市场品种的结构化分析与单次问答、个股六策略；选择参数后点击才调用当前账户模型；共享参考资料由管理员上传或删除 |

区间、指数、页签、K 线周期保存在页面 URL，便于回到同一视图。公共行情读取和后台采集不调用模型。共享资料支持 TXT、Markdown、PDF，单文件不超过 5 MB；它们会进入 K 线解读上下文，对本实例的登录账户共享。

资金页展示来源、日期及口径。公开订单分类和机构代理指标不能证明真实机构身份；缺少历史数据时显示为空，页面不补造记录。Tushare Token 已配置仅表示可以尝试访问，不保证该账户具备具体接口权限。没有 Token 时，公开指数仍可正常查看。

## 图表配置与布局

图表工具栏提供三种方案，选择后立即应用；自定义指标周期及显示设置会保留：

| 方案 | 主图与副图 |
|---|---|
| 简洁 | K 线与成交量，不叠加均线 |
| 趋势 | K 线、MA 均线与成交量 |
| 动量 | K 线、MA 均线、成交量与 MACD |

MA、BOLL 与副图也可单独选择；副图最多 3 个，按选择顺序排列，各自使用独立刻度，时间轴与十字光标联动。

点击 **图表设置** 从右侧打开设置抽屉。「显示」页可调整主图、副图、初始显示的 **40／80／120／240 根 K 线**、网格线与最新价线；最新价线表示已加载数据最后一根 K 线的收盘价。「指标参数」页可修改 MA、BOLL、MACD、KDJ、RSI 的周期与参数，周期按当前 K 线根数计算，例如周 K 的 20 表示 20 周。参数不合法时显示具体错误。

抽屉中的修改点击 **应用** 后生效；**取消**、关闭抽屉均放弃未应用的修改。「恢复参数」仅重置指标参数，「恢复默认」重置指标、参数与显示设置，均需点击应用。已应用的设置按账户与页面保存在当前浏览器。

显示根数控制初始视窗，不改变后端请求的历史区间，也不减少计算指标所用的已加载历史；数据少于所选根数时显示全部。调整指标、网格或主题时保留当前缩放范围；切换品种、历史区间、K 线周期或修改显示根数时，按所选根数重新定位。数据不足的指标位置留空。

图表、市场解读及单次问答使用同一品种目录。模型上下文包含交易所、报价单位、时间与缓存状态；解读仍需用户手动发起并配置模型。美股/期货不显示尚未支持的指数监控入口。

## 历史区间、周期与交易日

市场研判的 3 个月、6 个月、1 年、2 年、5 年按品种时区中的日历日期计算。A 股使用上海时区，美股及目录中的商品期货使用纽约时区。A 股日／周／月 K 在统一入口筛选，因此「1 年月 K」不会把一年误解成 280 个月。海外周／月 K 先由已取得的日线合成，再按日历区间筛选。

周／月 K 以**周期与所选日期窗口相交**为保留条件：若区间从某月 30 日开始，该月整根月 K 可以保留，已有的开、高、低、收与成交量不会被截成最后两天。来源提供 `period_end` 时采用其实际结束日期；A 股原生周期线没有该字段时，只用所在自然周或月判断是否相交，不把推算出的周末、月末写成实际行情日期。首根 K 线因此可能起于所选区间之前；上游只返回部分周期数据时，也不会补齐不存在的日线。进行中的周／月仍可随新日线更新。

海外周／月图的「数据截至」保留最后一根日线的交易日，区别于合成 K 线的起始标签；A 股原生周／月线沿用来源标注日期，来源只给出周期起点时，不擅自推算成实际期末成交日期。缓存写入时间另行显示。展示区间与周期改变后，最新周期的 OHLC、成交量和上一周期收盘价按对应 K 线重算；非正价格基数不计算常规涨跌百分比。缺失交易日不补造 K 线，海外缺失成交量保留未知。

## 自动采集与缓存

`ENABLE_DATA_COLLECTION=true` 且数据中心自动采集开启时，后台 `public_market` 默认每 60 分钟采集 19 个市场品种的约一年日线，同时更新展示缓存、写入不可变数据批次与本地观测时间。不需要先打开页面，也不依赖股票列表、模型配置或 `ENABLE_SCHEDULER`。来源间隔、预算、并发与重试说明见 [数据中心](DATA_CENTER.md)。宏观授权数据和资金扩展面板按需读取；此任务不自动使用个人 Tushare 凭据。

A 股指数按东方财富、腾讯、新浪、Yahoo 等可用适配器回退。美股和商品使用 Yahoo chart 的两条服务地址；标普500、道琼斯和纳斯达克综合另有明确代码映射的 Stooq 日线备用。Yahoo 的两条地址属于同一提供商，不代表独立数据源；没有独立备用的品种在 Yahoo 全部不可用时保留历史或显示无数据。每个响应需通过有限数值、OHLC 关系、成交量和日期检查。商品期货允许真实负价格；缺失成交量保留未知。海外周／月线由交易所时区的日线合成，进行中的周期可继续更新。展示缓存 TTL 为 5 分钟，手动刷新可重新访问上游；新响应不能用更旧的末根行情覆盖已有缓存。同批并发请求共享获取结果，避免重复访问备用链。海外请求按主机串行；HTTP 429、401、403 会写入跨品种共享的持久冷却，429 默认至少等待 5 分钟，按有界 Retry-After 调整，避免同一受限地址被连续请求。

A 股源数据超过日线 14 天、周线 21 天、月线 45 天未更新，会标记陈旧；美股与期货的日线末日超过 7 天即标记陈旧，周／月视图沿用日线时效。这是发现停止更新来源的保守阈值，不是交易所日历，也不代表终端级实时性。所有来源失败时保留有效旧缓存及其原采集时间；过期数据不伪装成刚刚更新，不进入本轮成功基线归档。页面刷新失败时保留原图并提示。

美股与期货可复用同品种、经过校验的较长日线缓存。例如后台已有一年历史时，三个月、六个月视图可从中筛选，日／周／月视图也共用日线。是否可复用取决于**实际记录是否覆盖请求起点且在所选窗口内仍有记录**，不只看文件标注的区间；一年数据不能充作五年历史。接口 `range` 始终是本次请求的区间，`cache_source_range` 标明实际采用的缓存区间。

复用缓存保留原提供商、来源链接、数据截至日期与采集时间，不因打开另一个区间或改变图表设置而刷新观测时间。新鲜且有效的缓存可直接返回；强制刷新或缓存过期后访问上游失败，即使能够使用较长缓存，也仍标记 `cache_stale=true`，不会当作本轮采集成功。陈旧历史请以提示中的实际截至日期判断，不作为当前行情。


市场采集间隔可在数据中心设为 5–43200 分钟，默认 60 分钟（`DATA_COLLECTION_MARKET_INTERVAL_MINUTES` 仅影响未保存过的配置）。采集器最多同时拉取两个市场品种；每个完成后立即落盘进度，达到单任务预算时退出并续跑。失败品种按 2 分钟至 1 小时指数退避，健康品种继续自己的更新节奏；总任务的下次重试取最早可执行品种的时间，避免无效重试耗尽每日预算。服务重启保留进度，已完成且未到更新间隔的品种不会重复下载。行情读取不调用模型。

自动采集必须保持后端运行。Docker 的 API 服务默认启用独立的 `ENABLE_DATA_COLLECTION`；数据中心暂停或来源开关仍有效，已有配置不被覆盖。采集状态页记录的是实际尝试和成功情况，公开接口可能延迟、限流或中断，5 分钟调度不代表 5 分钟实时行情。手动刷新图表与后台采集计划独立。

Tushare 宏观和行业 K 线缓存 TTL 为 15 分钟，行业目录为 1 小时。缓存关联凭据指纹，凭据变化会重新尝试取数；上游失败时允许有效历史缓存回退并标记陈旧。空响应、NaN／无穷值、异常 OHLC、重复或乱序日期经过校验，不会覆盖有效行情。行业目录最多回看 14 个自然日，接口异常立即结束该次回溯。

## API 与数据

全部接口沿用本工作台认证；公开试用网关不开放本地市场研判及资料管理。

| API | 参数或用途 |
|---|---|
| `GET /api/macro/indices` | 19 个品种的 `key`、名称、分类、交易所、时区、单位、来源与合约口径 |
| `GET /api/macro/collection-status` | 各品种采集进度、上次成功、数据日期、错误码、重试时间及启用状态 |
| `GET /api/macro/index-kline` | `index_key=SH_COMP`、`range=3mo/6mo/1y/2y/5y`、`interval=1d/1wk/1mo`、可选 `refresh=true` |
| `GET /api/macro/catalog` | 宏观目录、是否需 Token、当前配置是否可尝试读取 |
| `GET /api/macro/kline` | `series_id`、`range`；公开的三类指数无需 Token |
| `GET /api/macro/sw-daily/indices` | 行业目录，可选 `trade_date=YYYYMMDD` |
| `GET /api/macro/sw-daily/kline` | `ts_code=801010.SI`、`range` |

文件跟随 `STOCKVIEW_DATA_DIR`：`kline_bundle_cache/` 为指数展示缓存，`tushare_daily_cache/` 为授权序列缓存，`data_center.sqlite3` 与 `datasets/market/public_market/` 保存任务、市场品种批次和观测修订，`kline_learning/` 保存共享参考资料。备份时保留整个数据目录，见 [本机配置与搬迁](LOCAL_SETUP.md)。
