# 市场研判与 ExStockNEWS 2.0 功能整合

从顶部 **工具 → 市场研判**（`/macro`）进入。本工作台复用现有图表、登录、配置、行情链与研究服务，整合 ExStockNEWS 2.0 的宏观与行业、资金概览、大盘解读和个股 K 线研究入口。原项目的账户、数据目录、API 密钥与上传资料没有自动复制；继续使用本工作台自己的数据目录与凭据。

## 页面功能

| 页签 | 功能与数据条件 |
|---|---|
| 大盘指数 | 上证指数、深证成指、创业板指、沪深300、上证50；公开行情，无需 Key；支持日／周／月、3个月至5年区间、MA/BOLL 主图及最多 3 个指标副图，参数可调，缩放联动（见[指标设置](KLINE_INDICATORS.md)） |
| 宏观与行业 | 上证／深成／创业板沿用公开行情；上海金 Au99.99、离岸人民币、布伦特及申万行业按当前账户 Tushare Token 与接口权限获取；周／月由日线合成 |
| 资金概览 | 行业资金多周期与反转、机构和情绪代理、北向与两融历史；展开后读取人气／热门概念，按输入查询 ETF 与个股资金流 |
| K线解读 | 大盘结构化分析与单次问答、个股六策略；选择参数后点击才调用当前账户模型；共享参考资料由管理员上传或删除 |

区间、指数、页签、K 线周期保存在页面 URL，便于回到同一视图。公共行情读取和后台采集不调用模型。共享资料支持 TXT、Markdown、PDF，单文件不超过 5 MB；它们会进入 K 线解读上下文，对本实例的登录账户共享。

资金页展示来源、日期及口径。公开订单分类和机构代理指标不能证明真实机构身份；缺少历史数据时显示为空，页面不补造记录。Tushare Token 已配置仅表示可以尝试访问，不保证该账户具备具体接口权限。没有 Token 时，公开指数仍可正常查看。

## 自动采集与缓存

`ENABLE_DATA_COLLECTION=true` 且数据中心自动采集开启时，后台 `public_market` 默认每 60 分钟采集五个指数的约一年日线，同时更新展示缓存、写入不可变数据批次与本地观测时间。不需要先打开页面，也不依赖股票列表、模型配置或 `ENABLE_SCHEDULER`。来源间隔、预算、并发与重试说明见 [数据中心](DATA_CENTER.md)。宏观授权数据和资金扩展面板按需读取；此任务不自动使用个人 Tushare 凭据。

公开指数按东方财富、腾讯、新浪、Yahoo／Stooq 等可用适配器回退。每个响应需通过有限数值、OHLC 关系、成交量和日期检查。展示缓存 TTL 为 5 分钟，手动刷新可重新访问上游；新响应不能用更旧的末根行情覆盖已有缓存。同批并发请求共享获取结果，避免重复访问备用链。

若源数据超过日线 14 天、周线 21 天、月线 45 天未更新，会标记陈旧。这是发现停止更新来源的保守阈值，不是交易所日历，也不代表终端级实时性。所有来源失败时保留有效旧缓存及其原采集时间；过期数据不伪装成刚刚更新，不进入本轮成功基线归档。页面刷新失败时保留原图并提示。

Tushare 宏观和行业 K 线缓存 TTL 为 15 分钟，行业目录为 1 小时。缓存关联凭据指纹，凭据变化会重新尝试取数；上游失败时允许有效历史缓存回退并标记陈旧。空响应、NaN／无穷值、异常 OHLC、重复或乱序日期经过校验，不会覆盖有效行情。行业目录最多回看 14 个自然日，接口异常立即结束该次回溯。

## API 与数据

全部接口沿用本工作台认证；公开试用网关不开放本地市场研判及资料管理。

| API | 参数或用途 |
|---|---|
| `GET /api/macro/indices` | 五个指数的 `key` 与名称 |
| `GET /api/macro/index-kline` | `index_key=SH_COMP`、`range=3mo/6mo/1y/2y/5y`、`interval=1d/1wk/1mo`、可选 `refresh=true` |
| `GET /api/macro/catalog` | 宏观目录、是否需 Token、当前配置是否可尝试读取 |
| `GET /api/macro/kline` | `series_id`、`range`；公开的三类指数无需 Token |
| `GET /api/macro/sw-daily/indices` | 行业目录，可选 `trade_date=YYYYMMDD` |
| `GET /api/macro/sw-daily/kline` | `ts_code=801010.SI`、`range` |

文件跟随 `STOCKVIEW_DATA_DIR`：`kline_bundle_cache/` 为指数展示缓存，`tushare_daily_cache/` 为授权序列缓存，`data_center.sqlite3` 与 `datasets/market/public_market/` 保存任务、指数批次和观测修订，`kline_learning/` 保存共享参考资料。备份时保留整个数据目录，见 [本机配置与搬迁](LOCAL_SETUP.md)。
