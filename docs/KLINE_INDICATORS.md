# K 线指标与呈现设置

个股 K 线、市场研判中的大盘／宏观／行业图和 K 线复盘共用指标设置。加载行情、切换日／周／月 K 或修改参数后，图表自动重算；修改指标只使用已经载入的行情，不调用大模型，也不会新增后台采集任务。

## 选择显示内容

- **主图**：可分别开启 MA 均线和 BOLL 布林线，也可同时显示或全部关闭。
- **副图**：可从成交量、MACD、KDJ、RSI 等指标中选择，最多同时显示 3 个；不选副图时只显示主图。每个副图使用独立数值轴，时间轴和缩放联动。
- **参数设置**：修改周期和系数后应用，可恢复默认。默认主图为 MA20／60／250，副图为成交量。

设置保存在当前浏览器，按账户和页面类别分别记录：个股、市场研判、复盘互不覆盖。市场研判的一组设置同时用于该页的大盘、宏观和行业图；更换股票或刷新页面会保留当前页面类别的设置。清除浏览器本地存储后恢复默认，不会修改服务器上的采集计划、模型配置或研究规则。

| 指标 | 默认参数 | 可调整内容 |
|---|---|---|
| MA | 20、60、250 | 均线周期 |
| BOLL | 20、2 | 均值周期、标准差倍数 |
| MACD | 12、26、9 | 快线周期、慢线周期、信号周期；快线必须小于慢线 |
| KDJ | 9、3、3 | RSV 窗口、K 平滑周期、D 平滑周期 |
| RSI | 6、12、24 | RSI 周期 |

图表中的参数代表当前 K 线的根数。例如周 K 的 BOLL20 使用 20 根周 K，不是 20 个自然日。滚动、缩放只改变可见范围，指标仍使用当前已载入、计算点之前的行情；扩大行情区间可能补足更长的预热数据。

## 计算口径

以下为本项目前端图表的实际口径：

- **MA**：最近 N 根有效收盘价的简单平均；连续历史不足 N 根时留空。
- **BOLL**：中轨为 N 根收盘价的简单平均；上／下轨为中轨加／减 K 倍总体标准差（方差分母为 N）。默认 20 根、2 倍可按需要调整。布林带默认值和传统简单均值方法可参阅[作者说明](https://www.bollingerbands.com/bollinger-band-rules)；价格处于带内不代表特定概率或收益保证。
- **MACD**：DIF 为快 EMA 减慢 EMA，DEA 为 DIF 的 EMA，柱线为 `2 × (DIF − DEA)`。每条 EMA 使用首个完整周期的简单均值初始化，再以 `2 / (N + 1)` 递推；默认 DIF 从第 26 根开始，DEA 和柱线从第 34 根开始。
- **KDJ**：完整 N 根高低价窗口计算 RSV；K、D 从 50 初始化，按各自平滑周期递推，J 为 `3K − 2D`。高低价相同时 RSV 取 50；J 可超出 0–100，不作截断。
- **RSI**：需 N 次连续有效价格变化，以首个 N 次变化的平均上涨／下跌幅度初始化，再按 Wilder 方法平滑。完全平盘为 50，只有上涨为 100，只有下跌为 0。

无效或缺失观测会使相关窗口留空或重新预热；缺少成交量／成交额不会补成零。宏观序列即使没有成交量，仍可计算具有完整价格输入的 MA、BOLL、MACD、KDJ、RSI。由日 K 合成的周／月 K 不会把最后一天的换手率当作整个周期的换手率，该副图对应数值留空。

后端部分指标使用 [MyTT](https://github.com/mpquant/MyTT/blob/main/MyTT.py)，其 EMA 使用首值初始化，与上述前端预热方式不同；数据区间、复权方式和源数据也可能不同。因此图表与后端策略数值、其它终端数值不保证逐点一致。页面参数只控制此处的图形计算与显示，不改写后端策略公式。

## 复盘的历史边界

复盘先截断至当前回放日，再合成周／月 K，最后计算所有选定指标。当前尚未结束的周／月只包含已经揭示的交易日；未来行情不会参与 MA、BOLL 或任何副图。更改指标会暂停自动播放，便于查看调整结果。

当前回放日之前的可用历史不足某指标预热长度时，该段显示空白；不会借用尚未播放的数据填补，也不会拼入实时行情。图表指标是观察工具，不会自行生成买卖指令或触发下单。

实现入口：`frontend/src/KlineIndicatorControls.jsx`（设置）、`frontend/src/klineIndicators.js`（计算）、`frontend/src/klineChartOption.js`（主副图）和 `frontend/src/replayViewModel.js`（历史截断与合成）。
