# StockViewAgent

一个 A 股研究工具，把行情、不同策略的观点、新闻和公司资料放在同一页，方便跟踪关注的股票。

## 今日变化与关注判断

从顶部 **今日变化**（`/today`）集中查看自选股的新资料、新闻更正、主动关联的经济事件变化和到期复盘。首屏展示优先事项，其余可展开；每条保留来源、版本、发布时间和本地发现时间，可标为已读、有用或无关。首次扫描建立基线，已有资料标为「近期概览」，来源缺失或过期会明确提示。

在多策略观点或新闻解读中点击 **保存为关注判断**，记录关注理由、观察条件、证伪条件和复盘日期，默认 30 个自然日后检查。新资料会与同一股票的判断关联为待核实证据；支持、反证或暂无法判断由你确认。修改与复盘保留当时的判断和证据，结束跟踪也不会删除历史。经济事件须主动关联，日程已过不表示结果已公布。

后台在北京时间 16:30 后扫描已落库资料，重启后补处理；也可手动刷新。这个功能不新增必需的模型调用，不依赖严格历史行情，暂停候选研究时仍可维护。关闭自动运行会停止后台扫描，手动刷新仍只读取本地资料，不会触发外部采集。数据截止和覆盖状态以页面显示为准。

判断、证据时间线和反馈存入数据目录的 `tracking.sqlite3`，按账户隔离，随整个数据目录备份与迁移，不属于可清理缓存。现有决策信号继续使用其原有方向评价口径，个人关注判断不据此自动判定成败。

首轮可用自己的自选股连续试用 10 个交易日：每天记录处理用时、标记条目「有用／无关」，以及是否仍需逐股翻阅。复盘时分别检查经营证据与行情表现。约 5 分钟完成重点检查、展示条目多数有用是待验证目标，不能由功能测试代替真实使用验证。

搜索股票、批量添加到列表，选中后查看 K 线、均线、成交量和行情指标，支持日 K、周 K、月 K 切换。

## 多策略观点

价值投资、质量成长、均值回归、事件驱动等观点并列展示。每张卡片列出判断方向、观察周期、分析依据和风险提示，可以展开查看详细分析，也可以指定历史日期生成策略观点。

## 新闻解读

集中查看与个股相关的新闻和解读，按时间或重要性排序，并保留原文入口。可以更新新闻，也可以为待解读的内容补充分析。

## 雪球评论精选

从最近 200 条个股讨论中，由模型筛选有研究参考价值的内容，展示观点摘要、入选理由、风险提示和原文链接，最多保留 20 条。

支持手动更新最近讨论或昨日讨论。启用定时更新并保持服务运行后，每天北京时间 09:00 整理关注股票前一天的讨论。若雪球要求登录或验证，需要先完成后再更新。

## 公司资料

查看公司简介、所属行业、主营业务，以及近期公告和资讯。资料附有来源和更新时间，便于核对；更新失败时保留上次结果并提示。

## 全球经济金融事件日历

在 `/calendar` 查看央行会议、通胀、就业和经济增长等重要日程，按月份、地区、类别与重要性筛选，并查看来源、采集状态与修订记录。内置美联储、欧洲央行、日本央行、中国统计局和美国劳工统计局官方日历；默认由数据中心按每小时到期间隔、队列和预算调度，也可手动刷新。来源未提供的实际值、预期和前值保留为空，已过日程不等于已确认结果。

在 **经济日历 → Agent 解读与检索** 为当前账户配置新闻、多策略、量化研究、K 线与市场研判的事件证据，设置地区、重要性、回看/前瞻窗口和检索条数。事件持久化后进入全文检索索引，检索到的片段及来源、修订版本进入实际解读事实包；历史分析只读取当时已经采集的版本。数据覆盖、RAG 机制与使用边界见 [经济事件日历说明](docs/GLOBAL_EVENTS.md)。

## 本地研究实验室

在 `/research` 查看数据积累、候选策略、实验比较和模拟账户。独立 worker 在预算内生成受限策略规则、回测、保存失败原因，并从固定 GitHub 来源学习研究方法。策略通过历史验证后进入前向观察，证据达标才会替换模拟策略，也可回滚上一版。

研究数据和任务在本机持久保存，支持重启续跑与补采。普通行情缓存用于探索；自动晋升还需要完整的历史交易状态与时点证据，以及至少 60 个前向交易日。当前仅支持研究与模拟。操作、数据导入和备份见 [研究实验室说明](docs/RESEARCH_LAB.md)。

## 开始使用

项目在本机运行，需要 **Python 3.11–3.13** 和 **Node.js 20+**。

```bash
git clone https://github.com/fxfxfx99/StockViewAgent.git
cd StockViewAgent
./start.sh
```

脚本检查并准备项目依赖，启动服务后自动打开 [本地页面](http://127.0.0.1:5175/)。在 **设置 → 连接与数据** 选择大模型供应商、填写 API Key，点击 **保存并开启自动运行**；自定义接口再填写地址与模型。免费公开行情默认启用，付费行情账户放在可选高级设置中。

新账户会准备 5 只示例自选，已有列表和主动清空的列表不会被覆盖。在 **设置 → 运行日志** 查看自动运行状态、模型用量与采集记录；后台按预算采集、验证策略并维护模拟记录。本地监督器会尝试恢复服务意外退出，停止或电脑重启后需再次运行 `./start.sh`；也可使用 Docker 的重启策略。安装、日志及常见问题见 [使用说明](docs/LOCAL_SETUP.md)。

## 数据保存与搬迁

持续积累的数据默认集中在 `backend/data/`：行情与研究证据、新闻和公司资料、上传原件、CSV、账户与已保存的 API 配置，以及 `runtime/` 下的日志和运行状态。目录内的 `INDEX.md` 与 `_managed/catalog.json` 提供分类说明和文件索引；**设置 → 连接与数据 → 高级设置** 可查看实际位置、大小并刷新索引。

可用 `STOCKVIEW_DATA_DIR` 指定其它目录，修改后需重启。停服务后使用 `scripts/storage.py migrate` 校验复制到新目录，原目录保留；迁移会一并携带已有账户与 API 配置，外置 `.env` 和环境变量需另配。命令与升级兼容说明见 [本地数据目录与搬迁](docs/LOCAL_SETUP.md#本地数据目录与搬迁)。

## 本地数据中心

管理员从 `/data` 管理分类文件、采集任务和缓存。默认自动补充行情、新闻、公司资料、资金流、经济日历，以及欧洲央行参考汇率、世界银行年度指标和央行政策公告，共 11 类任务；公开资料保留批次、修订与本地观测时间，并可进入 Agent 的实际检索。

缓存可先预览、再移入可恢复回收区；自动回收默认关闭，数据库、研究证据、上传与账户配置长期保护。回收仍占用磁盘，只有手动确认永久删除才移除文件。来源覆盖、采集预算、RAG 和保留策略见 [数据中心说明](docs/DATA_CENTER.md)。
